Printer (office PC)

  1. Load 4×6 thermal labels. Run the printer's own calibration so it finds the label gap.
  2. Print the size-check label. The 1-inch marks should measure exactly 1 inch and the border should sit on the label edges. If it's shrunk, set scale to 100% / Actual size in the print dialog, or set the paper size to 4×6 in the printer driver.
  3. Print 3 test labels and scan them in the Scan test tab.

Android scanner

  1. Set the scanner to keyboard / keystroke output (on Zebra devices this is the DataWedge app; Honeywell/Chainway/Urovo have a "Scan settings" screen). It must not be set to "intent/broadcast".
  2. Turn on an Enter suffix (sometimes called "send ENTER key" or "suffix CR").
  3. Open this page on the device (or on a PC with the scanner connected), go to Scan test, and scan. Each scan should appear as one line in the log with a green result.
  4. Try from different distances and angles, in a dim trailer, and on a wrinkled label. Try the barcode and the QR separately, covering the other with your hand.

What to report back: scanner model, whether it reads the barcode, the QR or both, the max distance that works, and whether any scan came through wrong or split into two lines.
