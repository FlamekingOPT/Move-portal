Manager approvals: same model as the picker portal

  • Separate Outbound and Inbound screens (tap the toggle). Outbound: loads to ship, open loads, print queue. Inbound: receipts to approve, catch-ups, trucks in transit.
  • Floor workers only scan, so they need no new NetSuite access.
  • Only managers create the transfer order / IF / receipt: Approve & Ship, Approve Receipt, Approve catch-up.
  • The stock check blocks shipping a SKU when NetSuite's available quantity is lower than what's on the truck.
  • After Approve & Ship, the load sheet prints on the office printer.

⚠ The manager role will likely need Transfer Order + Item Receipt permission added. To confirm in sandbox.

Label code (office setting, applies to all labels):
  • SKU and piece count are readable from a distance.
  • Code128 barcode and QR code are stacked and hold the same PLT id. Pick one in the setting above if your scanners read both. One trigger pull reads one code, and a repeat scan just shows 🟡 "already on this load", so a double scan can't add a pallet twice.
  • No dims. Weight is left off.
  • EDITED shows when the count differs from the config.
  • The header card starts each batch so the stack is easy to hand out.
